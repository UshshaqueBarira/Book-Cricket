# 📖 Nostalgia Book Cricket Championship

A web application built with **Python** and **Streamlit** that brings back the golden memories of childhood **Book Cricket**! Gather 2 to 4 friends, flip through virtual book pages, score runs, and battle it out for the championship trophy.

---

## ✨ Features

* **Multiplayer Support:** Play with 2, 3, or 4 players with custom names and player avatars.
* **3D Book Flipping Animation:** Realistic page-flipping motion every time you take a turn.
* **Authentic Scoring Logic:** Random page generation (1–450) where the last digit determines your runs (0 to 6).
* **Nostalgic Sound Effects:** Built-in web audio synthesis for page flips, boundary cheers, "OUT" buzzers, and a championship victory fanfare!
* **Optional "OUT" Rule:** Turn on the classic schoolyard rule where hitting a page ending in `0` closes your innings.
* **Book Themes:** Choose between a *Math Textbook*, *Comic Book*, or *Classic Novel* visual style.
* **Winning Celebration:** Full confetti drop and roaring applause when the champion is crowned.
* **Persistent High Scores:** Tracks your best records locally using browser storage.
